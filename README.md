# voiceConnect
VoiceConnect is a social media web application inspired by platforms like Facebook and Instagram, but with a unique feature — Voice Posts 🎧. This application allows users to share thoughts not only through text posts but also using voice recordings, creating a more expressive and interactive social experience.
VoiceConnect – Voice Based Social Media Web Application
🚀 Features
👤 User Registration & Authentication
📝 Create Text Posts
🎙️ Create Voice Posts
@ Like & Interact with Posts
📰 News Feed System
📱 Responsive User Interface
🛠️ Admin Panel (Django Admin)
🛠️ Technologies Used
Frontend: HTML, CSS
Backend: Django (Python)
Database: SQLite
Media Handling: Django Media Files (for voice uploads)
📌 Project Objective
The objective of this project is to build a modern social media platform with voice-based interaction, while strengthening full-stack development skills using Django framework.
